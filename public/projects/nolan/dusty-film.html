How we're making Dusty's movie

Everything above is built from code. The robot is the same CAD model we 3D print from, Rev A.6. The kitchen, the chip bag and all the crumbs are generated by this page. Nothing is hand-animated and nothing is a downloaded model.

1

Design the parts in code DONE

Every printed part of Dusty is a Python program. Change one number, rebuild, and every part, print plate and download updates together. Each change gets a change order (MOC) so we know why it happened.

2

Put it together on the computer DONE

assemble.py places every part where it sits on the real robot, adds the parts we buy (N20 motors, micro:bit, moto:bit, power bank, QTR-1A sensors) and checks that nothing overlaps before anything gets printed.

3

Export it for the web DONE

The whole assembly is saved as one 3D file (GLB), and every part is tagged with its system: brain, power, drive, sensors, sweeper or tray. That tag is what lets the movie light up one system at a time.

4

Build the kitchen out of math DONE

The counter, sink, faucet, tile, chip bag and crumbs are shapes and formulas in three.js. The crumbs are scattered from a fixed random seed, so the same crumbs land in the same spots every time the movie plays.

5

Script the robot DONE

Dusty sweeps in rows like a lawnmower. The page checks every crumb against the roller as Dusty drives and only keeps crumbs the roller will reach, so the counter really does end up clean. The edge stop uses the design numbers: sensors ahead of the wheels, stop the moment the table disappears.

6

Light it like a movie DONE

One warm light under the cabinet, cool moonlight from the side, reflections from a studio environment map, and a glow filter that only catches very bright things, like Dusty's red LED eyes.

7

Sound DONE

Narration is 15 separate ElevenLabs clips read like a nature documentary, each placed at its moment in the movie, so any line can be redone on its own. The motor whir, crumb crunch, beeps, kitchen hum and both music cues are synthesized in code, and the music automatically gets quieter whenever the narrator talks.

8

Nolan's voice and face NEXT

Swap the narrator for a voice model of Nolan's voice. The eye and face patterns on the micro:bit are placeholders until Nolan designs his own.

9

Render every frame NEXT

A robot web browser steps the movie one frame at a time, 60 frames per second, and saves each one. Then the frames and the voice clips are stitched into the final video. No screen recording, no skipped frames.
